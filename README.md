# Catálogo & Carrito de Compras

Proyecto web interactivo que incluye un catálogo de productos con funcionalidad de carrito de compras.

## Tecnologías utilizadas
* **HTML5** - Estructura de la página
* **CSS3** - Diseños y estilos visuales
* **JavaScript** - Lógica del carrito y renderizado dinámico

## Funcionalidades
- [x] Catálogo de productos dinámico
- [x] Agregar y quitar productos del carrito
- [x] Cálculo automático del total
- [x] Persistencia de datos en localStorage
